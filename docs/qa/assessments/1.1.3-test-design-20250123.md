## Risk Coverage

- **SETUP-001**: Admin creation failures → UNIT-001, INT-001, E2E-001
- **SETUP-002**: Environment setup timing → E2E-003, E2E-004
- **DATA-001**: Sample data corruption → UNIT-002, INT-002, INT-003
- **SECURITY-001**: Improper admin permissions → INT-007
- **RECOVERY-001**: Database reset failures → INT-006, E2E-002
- **LOCALE-001**: Vietnamese data handling → INT-002

## Recommended Execution Order

1. **P0 Unit tests** (core logic validation)
   - UNIT-001: Environment variable parsing
   - UNIT-003: Health check logic validation

2. **P0 Integration tests** (critical system operations)
   - INT-001: Admin user creation via Auth API
   - INT-002: Vietnamese sample data loading
   - INT-004: Multi-component health verification
   - INT-006: Safe database reset functionality
   - INT-007: Admin permission verification

3. **P0 E2E tests** (critical workflows)
   - E2E-001: Complete admin creation workflow
   - E2E-003: Complete setup timing validation

4. **P1 tests** (important functionality)
   - UNIT-002: Sample data structure validation
   - UNIT-004: Role assignment logic validation
   - INT-003: Sample data referential integrity
   - INT-005: Programmatic role updates
   - E2E-004: Fresh environment setup workflow

5. **P2 tests** (optimization validation)
   - E2E-002: Reset preserves essential data
   - E2E-005: Documentation accuracy validation

## Test Implementation Guidelines

### Unit Tests
- Mock external API calls (Supabase Auth)
- Test configuration parsing and validation
- Validate business logic for data generation
- Fast execution for immediate feedback

### Integration Tests
- Use test containers for database operations
- Test actual API interactions with Supabase
- Verify data loading and integrity
- Include Vietnamese character handling

### E2E Tests
- Full environment setup/teardown testing
- Timing validation for setup processes
- Complete workflow validation
- Include error scenario recovery

## Test Data Requirements

### Environment Configuration
- Valid and invalid environment variable combinations
- Multiple environment types (dev, staging, prod)
- Various admin user configurations
- Database connection scenarios

### Vietnamese Sample Data
- Customer names: Nguyễn Văn An, Trần Thị Bình, Lê Hoàng Cường
- Phone numbers: 0901234567, 0812345678, 0987654321
- Repair descriptions with Vietnamese technical terms
- Business addresses in Vietnamese format

### Security Test Data
- Admin user with shop_owner role
- Staff user with limited permissions
- Test scenarios for role-based access
- Permission verification test cases

## Notes for Implementation

- All scripts must handle both Unix and Windows environments
- Vietnamese character encoding must be preserved throughout setup
- Health checks should provide detailed error messages
- Setup timing tests should account for system variability
- Include rollback procedures for failed setups
- Document common failure scenarios and solutions
- Ensure setup scripts are idempotent (can run multiple times safely)
