## Schema Issues & Fixes (2025-09-24)

### Issue 1: Multiple Foreign Key Relationships
**Problem**: `repair_tickets` table has multiple foreign keys to `user_profiles` table causing query ambiguity.
```
repair_tickets.assigned_technician_id → user_profiles.id
repair_tickets.paid_by → user_profiles.id
repair_tickets.repair_completed_by → user_profiles.id
```

**Solution**: Use explicit foreign key names in Supabase queries:
```typescript
// ❌ Ambiguous - causes PGRST201 error
technician:user_profiles(*)

// ✅ Explicit foreign key relationship
technician:user_profiles!repair_tickets_assigned_technician_id_fkey(*)
```

### Issue 2: Missing Columns
**Problem**: Frontend queries referenced missing `part_number` column in parts table.

**Solution**: Added missing column to database:
```sql
ALTER TABLE parts ADD COLUMN IF NOT EXISTS part_number TEXT;
```

### Issue 3: Invalid Supabase Query Patterns
**Problem**: Column-to-column comparison queries not supported by Supabase REST API:
```typescript
// ❌ Invalid - causes 22P02 error
.or("current_stock.lte.min_stock_level,current_stock.eq.0")
```

**Solution**: Use client-side filtering after data fetch:
```typescript
// ✅ Correct approach
const { data } = await supabase.from("parts").select("*");
const lowStockParts = data.filter(part =>
  part.current_stock <= part.min_stock_level || part.current_stock === 0
);
```
