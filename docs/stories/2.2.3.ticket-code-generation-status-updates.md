# Story 2.2.3: Ticket Code Generation & Status Update System

## Status
Approved

## Story
**As a** repair shop staff member,
**I want** automatic repair ticket code generation in LRP-YYYY-XXXXXX format with real-time status updates,
**so that** I can maintain professional ticket tracking and provide customers with reliable repair status information.

## Acceptance Criteria

1. **Automatic Code Generation**: Tickets automatically receive unique codes in LRP-YYYY-XXXXXX format using database sequences
2. **Vietnamese Year Format**: Year component follows Vietnamese date conventions with proper formatting
3. **Sequential Numbering**: Six-digit sequence numbers that increment properly within each year
4. **Code Uniqueness**: Database-level constraints ensure no duplicate ticket codes can be created
5. **Real-Time Updates**: Status changes propagate immediately to all connected clients and interfaces
6. **Vietnamese Status Messages**: All status update messages displayed in Vietnamese with clear descriptions
7. **Update Validation**: Status updates validated against business rules before being applied
8. **Change Attribution**: All status changes tracked with staff member attribution and timestamps
9. **Customer Notifications**: Automatic customer notification system for significant status changes
10. **Status History**: Complete chronological history of all status changes for each ticket
