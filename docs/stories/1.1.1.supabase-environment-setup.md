# Story 1.1.1: Supabase Development Environment Setup

## Status
Draft

## Story
**As a** development team member,
**I want** a complete local Supabase development environment with Docker containers and proper configuration,
**so that** I can develop and test the repair management system locally without external dependencies.

## Acceptance Criteria

1. **Docker Environment**: Supabase services run in Docker containers with proper port mappings
2. **Database Configuration**: PostgreSQL database accessible on localhost with repair shop schema
3. **Service Availability**: All Supabase services (Auth, API, Storage, Realtime) accessible locally
4. **Configuration Management**: Environment variables and configuration files properly organized
5. **CLI Integration**: Supabase CLI commands work correctly for migrations and management
6. **Development Database**: Test database with proper Vietnamese collation and timezone settings
7. **Port Management**: No conflicts with standard development ports (3000, 5173, etc.)
8. **Documentation**: Setup instructions that allow fresh environment creation in under 10 minutes
9. **Service Health**: Health check endpoints available for all critical services
10. **Vietnamese Locale**: Database configured with Vietnamese locale support (Asia/Ho_Chi_Minh timezone)

## Tasks / Subtasks

- [ ] **Task 1: Docker Configuration** (AC: 1, 3, 7)
  - [ ] Configure supabase/config.toml with appropriate port mappings
  - [ ] Set up Docker Compose override files for local development
  - [ ] Configure service health checks and dependency ordering
  - [ ] Test container startup and service availability

  - [ ] Configure database collation for Vietnamese text sorting

- [ ] **Task 3: Supabase Services** (AC: 3, 5, 9)

  - [ ] Write troubleshooting guide for common issues

## Dev Notes

### Relevant Source Tree Information:
- **Configuration**: `supabase/config.toml` (main Supabase configuration)
- **Environment**: `.env.local` (local development variables)
- **Scripts**: `package.json` (setup and management scripts)
- **Documentation**: `README.md` (setup instructions)

### Technical Context:
- Uses Supabase CLI v1.x for local development
- Docker containers for all backend services
- PostgreSQL 15+ for database with Vietnamese support
- Local file storage for development uploads

### Architecture Patterns:
- Service-oriented architecture with Docker containers
- Environment-based configuration management
- Health check patterns for service availability
- Local-first development with cloud parity

### Testing
- **Test Location**: `tests/setup/environment.test.ts`
- **Testing Framework**: Node.js scripts for environment verification
- **Test Requirements**:
  - All services respond to health checks
  - Database connection and query execution
  - Auth service can create test users
  - Storage service can handle file operations
  - Realtime connections work properly
