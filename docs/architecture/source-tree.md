# Source Tree Documentation

## Project Structure Overview

```
src/
├── components/              # React components
│   ├── pages/              # Page-level components (business logic)
│   ├── ui/                 # shadcn/ui reusable components
│   ├── app-sidebar.tsx     # Main application sidebar
│   ├── nav-*.tsx          # Navigation components
│   └── *.tsx              # Other shared components
├── hooks/                  # Custom React hooks
├── lib/                    # Utilities and helpers
├── routes/                 # File-based routing (TanStack Router)
├── styles.css             # Global styles and Tailwind CSS
├── main.tsx               # Application entry point
└── routeTree.gen.ts       # Auto-generated route tree
```

## Detailed Directory Structure

### `/src/components/`
React components organized by purpose and reusability.

#### `/src/components/pages/`
**Purpose**: Page-level components containing business logic for each route.

- `AdminPage.tsx` - System administration interface
- `CustomersPage.tsx` - Customer management (khách hàng)
- `DashboardPage.tsx` - Main dashboard with statistics and quick actions
- `HomePage.tsx` - Customer-facing homepage with ticket lookup
- `LoginPage.tsx` - Staff authentication page
- `PartsPage.tsx` - Parts inventory management (linh kiện)
- `RepairTicketsPage.tsx` - Repair ticket management (phiếu sửa chữa)
- `SetupPage.tsx` - Initial system setup

**Conventions**:
- Each page exports a single default component
- Component names match the route purpose
- Vietnamese business logic implemented
- shadcn/ui components used throughout

#### `/src/components/ui/`
**Purpose**: Reusable UI components from shadcn/ui library.

**Core Components**:
- `button.tsx`, `card.tsx`, `input.tsx` - Basic form elements
- `dialog.tsx`, `sheet.tsx` - Modal and overlay components
- `dropdown-menu.tsx`, `select.tsx` - Selection components
- `sidebar.tsx`, `breadcrumb.tsx` - Navigation components
- `alert.tsx`, `badge.tsx` - Status and feedback components
- `table.tsx`, `tabs.tsx` - Data display components

**Styling Components**:
- `avatar.tsx`, `separator.tsx` - Visual elements
- `skeleton.tsx`, `sonner.tsx` - Loading and notification states
- `collapsible.tsx`, `tooltip.tsx` - Interactive elements

#### `/src/components/` (Root Level)
**Application-specific components**:

- `app-sidebar.tsx` - Main application sidebar with Vietnamese navigation
- `nav-main.tsx` - Main navigation with collapsible sections
- `nav-projects.tsx` - Reports navigation (adapted for repair shop)
- `nav-user.tsx` - User profile dropdown
- `team-switcher.tsx` - Shop selection component
- `AdminPanel.tsx` - Legacy admin component
- `Header.tsx` - Legacy header component (currently unused)

### `/src/routes/`
**Purpose**: File-based routing with TanStack Router.

**Route Files**:
- `__root.tsx` - Root layout and providers
- `index.tsx` - Homepage route (`/`)
- `login.tsx` - Login page (`/login`)
- `dashboard.tsx` - Dashboard route (`/dashboard`)
- `admin.tsx` - Admin panel (`/admin`)
- `khach-hang.tsx` - Customers page (`/khach-hang`)
- `linh-kien.tsx` - Parts inventory (`/linh-kien`)
- `phieu.tsx` - Repair tickets (`/phieu`)
- `setup.tsx` - System setup (`/setup`)

**Auto-generated**:
- `routeTree.gen.ts` - Generated route tree (do not edit manually)

### `/src/hooks/`
**Purpose**: Custom React hooks for shared logic.

- `use-mobile.ts` - Mobile device detection for responsive behavior

### `/src/lib/`
**Purpose**: Utility functions and shared logic.

- `utils.ts` - Utility functions (cn function for className merging, etc.)

### Root Files

- `main.tsx` - Application entry point, React root mounting
- `styles.css` - Global styles, Tailwind CSS imports
- `logo.svg` - Application logo asset
- `reportWebVitals.ts` - Performance monitoring setup

## File Naming Conventions

### Components
- **PascalCase** for component files: `DashboardPage.tsx`
- **kebab-case** for shadcn/ui components: `dropdown-menu.tsx`
- **Page components** suffix with `Page`: `LoginPage.tsx`

### Routes
- **kebab-case** for route files: `khach-hang.tsx`
- **Vietnamese route names** for business context
- **Index files** for root routes: `index.tsx`

### Utilities
- **kebab-case** for utility files: `use-mobile.ts`
- **Descriptive names** that explain purpose

## Import Patterns

### Absolute Imports
```typescript
import { Button } from "@/components/ui/button"
import { cn } from "@/lib/utils"
import { useIsMobile } from "@/hooks/use-mobile"
```

### Relative Imports
Used sparingly, mainly for co-located files.

## Vietnamese Business Context

The source tree reflects a Vietnamese laptop repair shop workflow:

- `khach-hang` (customers) - Customer management
- `linh-kien` (parts) - Inventory management
- `phieu` (tickets) - Repair ticket workflow
- Vietnamese component names and business logic throughout

## Auto-generated Files

**Do not manually edit**:
- `src/routeTree.gen.ts` - Generated by TanStack Router
- Any `.gen.ts` files

**Safe to edit**:
- All `.tsx` component files
- Route files in `/src/routes/`
- Utility files in `/src/lib/` and `/src/hooks/`

## Development Workflow

1. **Pages**: Create new page components in `/src/components/pages/`
2. **Routes**: Add corresponding route files in `/src/routes/`
3. **Components**: Add reusable components to `/src/components/`
4. **Utilities**: Add shared logic to `/src/lib/` or `/src/hooks/`
5. **UI Components**: Use `shadcn add` command for new UI components

## Build Artifacts

Generated during build process:
- `dist/` - Production build output (not in src)
- Route tree auto-generation on file changes
